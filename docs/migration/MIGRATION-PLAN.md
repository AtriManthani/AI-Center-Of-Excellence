# Initial Data Migration Plan

## 1. Approve the contract

- Resolve terminology and RACI items that affect stored fields.
- Approve vocabularies, lifecycle mapping, and inventory entry point.
- Confirm repository visibility and permitted data classifications.

## 2. Reconcile sources

- Establish the authoritative list of use cases.
- Assign or confirm permanent IDs.
- Reconcile current phases, owners, priorities, risk tiers, and dates.
- Reconcile license product names and capacity totals.
- Identify open operational issues and their source system.

## 3. Pilot records

Create a small representative set: one early-stage use case, one backlog item, one testing/pilot item, one production solution, and one closed/decommissioned solution. Validate each against supporting evidence.

## 4. Validate and review

Run repository validation, inspect the generated dashboard, and conduct business, governance, data, and security review as applicable.

## 5. Migrate remaining records

Add records in reviewed batches. Preserve source references and record the migration date. Do not use fictional examples as migration input.

## 6. Operationalize

Define update cadence, responsible editors, review controls, dashboard distribution, backups, retention, and future system integrations.
