# Documentation

## Purpose

This area contains documentation about the repository and the design of the AI COE operating system. It supports the three primary areas without becoming a second source of truth for program status, governance decisions, or inventory data.

## What belongs here

- Architecture and repository-design decisions
- Data-model documentation
- Migration plans and reconciliation notes
- Approved source-document references
- User guides and onboarding material
- Automation and integration documentation

## Source materials

The initial design is informed by:

- The draft City of Cleveland AI Governance Playbook
- The AI Inventory structure and dashboard design

Those files are not committed automatically. Before adding source decks or exports, confirm their classification, intended audience, ownership, and whether GitHub is an approved storage location.

## Documentation rules

- State whether a document is draft, proposed, or approved.
- Include an owner and last-reviewed date for operational guidance.
- Link to authoritative records rather than duplicating live status.
- Record unresolved questions explicitly.
- Do not place sensitive evidence, production data, or credentials here.

Every subfolder created under `docs/` should contain its own README or index.
