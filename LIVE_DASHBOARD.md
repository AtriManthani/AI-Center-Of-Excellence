# Live AI Center of Excellence Dashboards

- Open the **[AI Program dashboard](https://atrimanthani.github.io/AI-Center-Of-Excellence/)** for program-status presentations.
- Open the **[AI Inventory dashboard](https://atrimanthani.github.io/AI-Center-Of-Excellence/AI%20Inventory/)** for the latest approved use-case status.
- Open the **[AI License Management dashboard](https://atrimanthani.github.io/AI-Center-Of-Excellence/AI%20Licenses/)** for employee coverage and license-allocation reporting.

The [AI Program](AI%20Program/) folder contains the Excel source of truth for program reporting. The [AI Inventory](AI%20Inventory/) folder contains the public, non-sensitive governance workspace and its leadership presentation layer. The [AI Licenses](AI%20Licenses/) folder accepts the latest non-sensitive Excel license register and powers the license dashboard automatically.
