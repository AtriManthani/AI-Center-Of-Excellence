# AI Inventory

Open the **[live AI Inventory dashboard](https://atrimanthani.github.io/AI-Center-Of-Excellence/AI%20Inventory/)** to present the latest approved use-case statuses.

This public folder is the sanitized presentation layer. It must contain only leadership-approved information. Governance evidence, assessments, internal comments, and detailed issue records belong in the private AI Governance Workspace.

The dashboard reads `data/use-cases.json`, which is generated from allowlisted fields in the private workspace. Do not manually add sensitive information to that file.
