# AI-0000 — Use-case Name

This is the permanent home for one use case.

1. Rename this folder with the real ID and short name.
2. Update `status.json`; it controls the leadership summary and current dashboard position.
3. Update `governance.json`; it controls detailed phase, gate, review, risk, decision, and monitoring views.
4. Open the current phase folder.
5. Upload public-safe forms and review files directly into that folder.
6. Update the matching control IDs in `CHECKLIST.md` and `governance.json`.
7. Set `publish` to `true` when the record is ready to display.

Everything in this repository is public. Upload only non-sensitive information. Do not claim approval until the reviewing group has made and documented its decision. For internal evidence that cannot be published, use a public-safe label such as `Reviewed internally` without describing the sensitive finding.
