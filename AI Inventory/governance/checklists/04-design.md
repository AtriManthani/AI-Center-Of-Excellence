# Design

Playbook phase: Solution Design

## Core evidence

- [ ] Cross-functional delivery team assigned
- [ ] Data sources, access, ownership, and controls defined
- [ ] Data Release Committee review completed if needed
- [ ] Model, user, interface, and process requirements defined
- [ ] Risks, policies, mitigations, and fallback plans documented
- [ ] Success measures and monitoring KPIs defined
- [ ] Architecture and security design documented

## Gate questions

- [ ] Have the required teams reviewed the solution design?
- [ ] Are risks accounted for with planned mitigations?
- [ ] Are the data and model requirements appropriate?
- [ ] Is implementation approved to proceed?
