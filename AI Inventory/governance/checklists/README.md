# Phase checklists

These are the detailed master checklists from the Governance Playbook. Each use case also includes a control-ID checklist inside every plainly named phase folder.

Use the phase checklist for routine evidence collection. Update the matching control ID in the use case's `governance.json` so the dashboard can show requirement status, ownership, dates, and evidence. Refer to the master checklist when a more detailed governance review is needed.
