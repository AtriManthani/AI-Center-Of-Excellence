# ITS Project Tracking

This folder contains the public-safe source workbook and live leadership dashboard for the ITS project portfolio.

## View the dashboard

[Open ITS Project Tracking](https://atrimanthani.github.io/AI-Center-Of-Excellence/ITS%20Project%20Tracking/)

The dashboard presents information in this order:

1. What is done
2. What we are working on
3. What's coming up
4. Portfolio at a glance

## Update the dashboard

1. Open [Prepare Project Workbook](https://atrimanthani.github.io/AI-Center-Of-Excellence/ITS%20Project%20Tracking/prepare.html).
2. Select the original ITS project workbook on your computer.
3. Download the generated file beginning with `ITS_Project_Tracking_Public_`.
4. Delete the previous `.xlsx` file from this folder and upload only the prepared file.
5. Commit the change and refresh the dashboard after GitHub Pages finishes publishing.

The workbook filename may change. The dashboard automatically selects the most recently updated `.xlsx` file in this folder.

## Public-data requirement

The repository is public. Never upload the original workbook directly. The preparation page excludes named owners, named ITS leads, detailed risk narratives, internal tagging notes, and review comments while retaining the project delivery fields used by the dashboard.
