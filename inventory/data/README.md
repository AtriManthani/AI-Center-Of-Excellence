# Inventory Data

This folder contains approved machine-readable records used by validation and dashboard generation.

- `use-cases/` contains one JSON file per AI use case.
- `licenses/` contains one JSON file per license pool or approved product entitlement.
- `issues/` contains one JSON file per tracked operational issue.

Copy the relevant file from `shared/templates/`, replace all placeholders, and run the validator before review. Synthetic examples belong in `shared/examples/`, never in this folder.
