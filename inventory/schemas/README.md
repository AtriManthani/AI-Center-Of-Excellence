# Inventory Schema References

The canonical schemas are maintained in [`shared/schemas/`](../../shared/schemas/). This folder exists as the inventory-facing index so consumers can find the contracts without creating duplicate schema copies.

- Use cases: `shared/schemas/use-case.schema.json`
- Licenses: `shared/schemas/license.schema.json`
- Issues: `shared/schemas/issue.schema.json`
- Vocabulary: `shared/vocabularies/vocabularies.json`
- Lifecycle mapping: `shared/mappings/lifecycle-mapping.json`
