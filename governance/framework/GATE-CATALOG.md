# Governance Gate Catalog

| Gate | Decision | Minimum evidence |
| --- | --- | --- |
| G1 | Intake valid and complete? | Intake record, problem statement, benefit, stakeholders, AI-appropriateness screening |
| G2 | Valid or strategic opportunity? | Feasibility review, cost/benefit, strategic rationale |
| G3 | Risk acceptable? | Preliminary risk assessment and proposed mitigations |
| G4 | Approved and feasible to pursue? | Priority, capacity, budget, architecture, licensing, technical reviews |
| G5 | Build or buy? | Capability, capacity, platform, procurement, and vendor considerations |
| G6 | Design approved for implementation? | Solution design, data decision, controls, KPIs, schedule, reviewers |
| G7 | Outputs valid? | Development validation and trustworthy-attribute evidence |
| G8 | Testing passed? | Test plan, developer results, issue disposition |
| G9 | Pilot successful? | Business-user results, acceptance criteria, residual risk |
| G10 | Deployment approved? | Training, communications, monitoring, rollback, inventory record |
| G11 | Remediate or close out? | Monitoring signal, impact analysis, remediation feasibility, stakeholder impact |
| G12 | Closeout complete? | Contract, data, access, stakeholder, replacement, and retirement evidence |

Gate owners and required approvers must be updated when the final RACI is approved.
