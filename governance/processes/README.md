# Governance Processes

This folder documents repeatable workflows governed by the AI COE. It separates organizational use-case governance from individual access to an approved tool or feature.

- `USE-CASE-PROCESS.md` covers enterprise and departmental use cases.
- `INDIVIDUAL-ACCESS-PROCESS.md` covers individual licenses and feature access.

An individual request that is not for an approved tool or expands into a departmental capability must be routed into the use-case process.
