# Governed Use Cases

This folder will contain one directory per approved use-case record, named `AI-####-short-name`. Do not create a record from unverified sample content.

Each record should include a README, structured metadata conforming to `shared/schemas/use-case.schema.json`, and phase-specific evidence or controlled links. Use `shared/examples/AI-0001-example/` as a synthetic structural example only.

## Record rules

- Assign an ID only through the agreed intake process.
- Never reuse an ID.
- Record every gate outcome and date.
- Keep sensitive evidence in its authorized system.
- Update lifecycle fields through a reviewed change.
- Close the governance record only after the inventory outcome is reconciled.
