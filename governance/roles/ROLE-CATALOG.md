# Role Catalog

| Role | Working responsibility |
| --- | --- |
| AI Governance Council | Strategic oversight and decisions concerning investment, risk, policies, use cases, tools, and program measures |
| AI Center of Excellence | Facilitation, coordination, solution support, training, communications, monitoring, and escalation |
| AI Program Manager | Intake, backlog, cadence, project coordination, reporting, and governance administration |
| AI Architect | Architecture, design patterns, solution design, and technical coordination |
| UAI AI Lead/Data Governance | Data availability, quality, standards, sensitivity, release decisions, and data strategy alignment |
| Cybersecurity | Identity, data-loss prevention, security review, threat evaluation, and monitoring consultation |
| Applications | Platform administration, unstructured data preparation, integration, and application review |
| Infrastructure | Environment, network, and infrastructure review and support |
| Department Leadership | Sponsorship, business ownership, resources, adoption, and departmental decisions |
| AI Leads | Department liaison, intake support, adoption, and project participation |
| Platform Owners | Platform-specific feasibility, administration, and lifecycle responsibilities |
| Business Users/SMEs | Requirements, testing, feedback, adoption, and responsible use |

## Open responsibility decisions

- Final membership and naming of governance bodies
- Consolidated decision-point RACI
- Monitoring activity ownership
- Closeout activity ownership
- Required approvers for each risk tier
