# AI Program

This folder contains the AI Program change-management project plan and its presentation dashboard.

- Maintain `AI_Program_Change_Management_Project_Plan_v81_20260916.xlsx` as the source plan.
- Open `AI_PROGRAM_DASHBOARD.html` through a local web server or GitHub Pages. It reads the Excel file directly and recalculates whenever the workbook changes.
- If the dashboard is opened directly from a downloaded file, select **Load workbook** and choose the Excel file because browsers may block automatic local-file access.

The Excel workbook is the source of truth; dashboard figures are not maintained separately.
